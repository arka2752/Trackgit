About Trackgit

This dashboard is built entirely with HTML, CSS, and Vanilla JavaScript. It connects to the GitHub REST API and a public contribution proxy to fetch, analyze, and visualize developer profiles.

How the Developer Score is calculated

The 0-100 score uses a logarithmically scaled formula to account for the extreme variations in open source metrics (e.g., users with 0 followers vs 100,000 followers). It weights:

  • Repository Quality (30%): Average stars and forks across all public repos.
  • Followers (20%): Overall profile followers.
  • Activity (20%): How many repos have been pushed to within the last year.
  • Language Diversity (15%): Number of distinct languages used (capped at 6).
  • Repository Count (15%): Total public repos.

Technologies Used

  • HTML5, CSS3 (Flexbox/Grid), Vanilla JavaScript (ES6+)
  • GitHub REST API
  • Chart.js (CDN)
  • FontAwesome (CDN)
